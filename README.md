# Проверка кодов товаров на volgorost.ru

Приложение на **Streamlit** для проверки товаров по списку кодов на сайте [https://volgorost.ru/](https://volgorost.ru/).

## Возможности

- Загрузка кодов из `xlsx` файла (первая колонка).
- Ручной ввод кодов (каждый код с новой строки).
- Объединение кодов из файла и ручного ввода.
- Очистка кодов от лишних пробелов.
- Удаление дубликатов.
- Парсинг результатов поиска и переход в карточки товаров.
- Проверка совпадения значения поля **«Код»** с исходным кодом.
- Обработка сетевых ошибок, таймаутов и страниц `404`.
- Логирование ошибок в файл `app.log`.
- Отчет в формате `xlsx` со столбцами:
  - `Код`
  - `Ссылка на карточку товара`

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run main.py
```

## Как пользоваться

1. Загрузите `xlsx` файл с кодами (одна колонка) и/или вставьте коды вручную.
2. Нажмите **«Начать проверку»**.
3. Дождитесь завершения обработки.
4. Просмотрите таблицу результатов.
5. Скачайте `xlsx` отчет по кнопке **«Скачать XLSX отчет»**.

## Примечание

Так как структура HTML сайта может меняться, в парсере реализованы несколько эвристик поиска карточек и поля `Код`.
При необходимости селекторы можно адаптировать в `parser.py`.
